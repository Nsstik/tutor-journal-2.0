# Журнал успеваемости

Сайт для репетитора: учёт уроков, поведения, домашних заданий, оплаты и тем
«на подтянуть» по каждому ученику — с отдельным входом для родителей, где
каждый родитель видит только своего ребёнка, а графа «Оплата» показывается
только тем, кому вы её разрешили.

**Как запустить и куда деплоить — см. файл `SETUP.md`, там всё по шагам.**

## Что где лежит

- `supabase/schema.sql` — структура базы данных и правила доступа (кто что видит).
- `app/login` — вход и разовая регистрация вашего (репетиторского) аккаунта.
- `app/dashboard` — ваш кабинет: список учеников, уроки, темы, выдача доступа родителям.
- `app/parent` — то, что видит родитель (только для чтения).
- `middleware.js` — не пускает родителя в кабинет репетитора и наоборот.

## Технологии

Next.js 14 (App Router) + Supabase (база данных, авторизация, разграничение
доступа на уровне строк — Row Level Security). Шрифт — Times New Roman везде,
по вашей просьбе.
