# Журнал успеваемости — инструкция по запуску

Это обычный сайт (написан на Next.js), которому нужны два бесплатных сервиса:
- **Supabase** — база данных + логины/пароли;
- **Vercel** — где сайт будет «жить» (получит свой адрес вида `https://ваш-журнал.vercel.app`).

Всё делается через браузер, программировать не нужно. Займёт 20–30 минут в первый раз.

---

## Шаг 1. Создать проект в Supabase

1. Зайдите на **supabase.com** → «Start your project» → зарегистрируйтесь (можно через Google).
2. «New project»: название любое (например, `tutor-journal`), придумайте пароль базы данных (сохраните его отдельно, но в коде он не понадобится), регион — ближайший к вам.
3. Подождите 1–2 минуты, пока проект создастся.

## Шаг 2. Загрузить структуру базы данных

1. В меню слева откройте **SQL Editor**.
2. Нажмите «New query».
3. Откройте файл `supabase/schema.sql` из этого проекта, скопируйте **всё** содержимое и вставьте в редактор.
4. Нажмите **Run**. Должно появиться сообщение об успехе. (Если пишет, что что-то уже существует — это нормально при повторном запуске, ничего страшного.)

## Шаг 3. Достать ключи доступа

1. В меню слева: **Project Settings → API**.
2. Скопируйте три значения — они понадобятся на шаге 5:
   - **Project URL** → это `NEXT_PUBLIC_SUPABASE_URL`
   - **anon public** ключ → это `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - **service_role** ключ (он скрыт, нужно нажать «Reveal») → это `SUPABASE_SERVICE_ROLE_KEY`

   ⚠️ **service_role** ключ — секретный, он даёт полный доступ к базе. Никому его не показывайте и не публикуйте.

## Шаг 4. Придумать код регистрации

Придумайте любое слово или набор символов, например `Repet-2026-xk9`.
Это `TUTOR_SIGNUP_CODE` — код, который вы один раз введёте при регистрации СВОЕГО
аккаунта, чтобы никто посторонний не смог зарегистрироваться на сайте как репетитор.

## Шаг 5. Разместить сайт на Vercel

1. Зайдите на **vercel.com** → зарегистрируйтесь (проще всего через GitHub).
2. Если аккаунта на GitHub нет — заведите (github.com), это бесплатно.
3. Загрузите папку проекта на GitHub:
   - Самый простой способ: на github.com нажмите «New repository», назовите `tutor-journal»,
     затем на странице репозитория нажмите «uploading an existing file» и перетащите
     туда всё содержимое папки проекта (все файлы и папки из архива, который я вам передал).
4. В Vercel: «Add New… → Project» → выберите этот репозиторий → «Import».
5. В разделе **Environment Variables** добавьте четыре переменные (имя — значение):

   | Имя | Значение |
   |---|---|
   | `NEXT_PUBLIC_SUPABASE_URL` | из шага 3 |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | из шага 3 |
   | `SUPABASE_SERVICE_ROLE_KEY` | из шага 3 |
   | `TUTOR_SIGNUP_CODE` | из шага 4 |

6. Нажмите **Deploy**. Через 1–2 минуты сайт будет готов, Vercel покажет ссылку вида
   `https://tutor-journal-xxxx.vercel.app` — это и есть ваш постоянный адрес.

## Шаг 6. Зарегистрировать свой (репетиторский) аккаунт

1. Откройте ваш сайт → «Первый раз здесь? Зарегистрировать аккаунт репетитора».
2. Заполните имя, e-mail, пароль и код из шага 4.
3. После входа вы окажетесь в своём кабинете — можно добавлять учеников.

## Шаг 7. Выдать доступ родителю

1. Зайдите в карточку нужного ученика.
2. Внизу, в блоке «Доступ для родителя»: впишите e-mail родителя, отметьте
   галочку «показывать этому родителю», если ей нужно видеть оплату, и нажмите
   «Создать доступ».
3. На экране один раз покажется временный пароль — скопируйте и отправьте
   родителю вместе со ссылкой на сайт. Родитель заходит через кнопку «Вход»
   на главной странице, тем же e-mail и паролем.

---

## Если что-то не работает

- **«Invalid API key»** — проверьте, что скопировали ключи в шаге 3 без лишних пробелов.
- **Сайт не открывается после Deploy** — на вкладке проекта в Vercel откройте
  «Deployments», зайдите в последний деплой и посмотрите вкладку «Logs» — там
  обычно написано, какой переменной не хватает.
- Если захотите что-то изменить в дизайне или добавить поле — просто пришлите
  мне, что нужно, и я обновлю код.

## Как вносить изменения в будущем

Если что-то нужно поменять в коде, обновлённые файлы можно снова загрузить в
тот же GitHub-репозиторий (просто заменить файлы) — Vercel автоматически
пересоберёт и обновит сайт за 1–2 минуты.
